## 📖 About the Project

**JobTrack** is a responsive **Job Portal Application** designed to simplify job searching, application tracking, and interview management.

The project provides dedicated modules for **Jobs, Applications, Interviews, and Dashboard** with real-time filtering and status tracking.

---

## ✨ Features

- 💼 Browse Job Listings
- 🔍 Filter Jobs by Role, Location, Type
- 📝 Track Applications
- 📊 Manage Application Status - Applied, Interview, Rejected, Shortlisted
- 📅 View Interviews
- 📈 Dashboard with Stats
- 💾 LocalStorage Data Persistence
- 📱 Fully Responsive Design
- 🎨 Clean UI with CSS Grid & Flexbox

---

## 💼 Portal Modules

- 🔍 Jobs - Search and filter jobs
- 📝 Applications - Track all applications
- 📅 Interviews - Scheduled interviews
- 📊 Dashboard - Overview and analytics
